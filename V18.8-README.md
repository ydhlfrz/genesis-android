# Genesis V18.8 — Character Visual Transition

Patch untuk V18.7. Ini tahap penghentian fitur Prompt/Artwork di aplikasi Android, bukan penghapusan permanen data server.

## Perubahan
- Menu Prompt dikeluarkan dari Lobby.
- Halaman Prompt, Copy prompt, pemilih file, upload, preview artwork dan downloader thumbnail artwork dihapus dari MainActivity.
- Refresh tidak lagi membaca tabel genesis_character_media; fitur lain tidak menunggu data artwork.
- Lobby, Collection dan portrait Detail/Progression memakai emblem dari aset APK.
- baseRace digunakan sebagai identitas visual; jika kosong memakai race, lalu unknown. Loader lokal memiliki fallback unknown bila file tidak tersedia.
- Pemulihan route Prompt dari sesi lama diarahkan ke Lobby.
- Pilihan karakter lobby, nama, registry ID, favorit dan progression tetap digunakan.
- Data karakter/ekonomi dan formula engine identik dengan basis.

## Aturan migrasi
Tidak ada SQL yang harus dijalankan. File artwork dan metadata yang sudah ada di Supabase dipertahankan. Endpoint server lama belum dicabut, sehingga aplikasi versi lama masih dapat menggunakannya. Pencabutan endpoint dan penghapusan file server memerlukan tahap terpisah setelah versi lama dihentikan; patch ini tidak melakukan hal tersebut.
Cache thumbnail lama di cache aplikasi tidak dibaca lagi dan dapat dibersihkan oleh Android. File sumber ikon Prompt dan fungsi generator prompt Legacy di engine masih dipertahankan sebagai kompatibilitas arsip/test; tidak ada akses UI Android untuk memakainya.

## Persiapan karakter modular
Fungsi thumbnail menjadi titik masuk visual karakter di beberapa halaman. Untuk saat ini tetap emblem, bukan sprite atau karakter animasi. Produksi aset modular akan menggunakan standar ukuran/pivot/layer yang disepakati sebelum integrasi. Jangan mengganti seed atau fakta karakter lama untuk menentukan tampilan.

## Memasang
1. Ekstrak ZIP patch.
2. Upload folder app ke root repo V18.7 yang sama dan timpa MainActivity.java serta app/build.gradle.
3. Jalankan workflow Build Genesis Android pada commit baru. Konfigurasi SDK yang sudah diperbaiki tetap digunakan.
4. Setelah workflow berhasil, pasang APK sebagai pembaruan.
Tidak perlu SQL baru, mengganti Variables, menghapus repository, ataupun uninstall.

## Validasi
Sintaks 12 file Java berhasil diparse. Pemeriksaan memastikan MainActivity tidak memanggil media API/upload/prompt lagi. Backend dan aset engine dibandingkan byte-for-byte dengan V18.7 dan tidak berubah. Build Android/lint dan tampilan pada perangkat belum diuji di lingkungan ini.

## Uji perangkat
- Login akun yang pernah mengunggah artwork: lobby dan koleksi menampilkan emblem, tanpa tombol artwork.
- Detail, Progression, favorit, rename dan pilihan hero lobby tetap bekerja.
- Akun tanpa karakter tetap menampilkan Genesis mark.
- Halaman Prompt yang tersimpan dari versi sebelumnya membuka Lobby.
- Emblem ras yang file-nya tidak ditemukan memakai unknown.
- Pastikan menu bawah hanya Collection, Progression dan History.

Tahap berikutnya: optimasi ukuran aset serta rancangan paket unduhan. Belum ada perubahan ukuran PNG asli pada patch ini.
