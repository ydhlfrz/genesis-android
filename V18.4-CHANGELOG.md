# Genesis V18.4 — Navigation & Loading

Tahap 2, berdasarkan V18.3 yang sudah dicoba pengguna. Source Android lengkap, bukan APK.

## Perubahan
- Tombol Enter Sanctum: lebar 146dp pada kolomnya, ikon 64dp dan teks 13sp. Efek alpha berdenyut lembut.
- Menu kiri lobby: ikon 24dp di samping label 10sp; empat tombol memakai minimum 48dp, tanpa ScrollView tersendiri. Pada layar sangat pendek/font besar, scroll utama tetap tersedia.
- Semua operasi lewat task (startup, login, summon, upgrade, rename, favorite, dll.) menampilkan logo lokal Genesis, indikator berputar dan teks tengah. Keyboard ditutup agar loading terlihat.
- Animasi tambahan mengikuti Reduce motion, berhenti saat pause/destroy, dan tidak terus berjalan di halaman tanpa animasi tersebut.
- Header Back memiliki tinggi 48dp tanpa padding yang sebelumnya mengurangi ruang tombol. Back aplikasi dan Back sistem pada halaman game kembali ke Lobby. Dialog tetap ditutup oleh Back sistem; transaksi aktif tetap dilindungi.
- Pindah halaman melalui gotoPage menutup keyboard dan mengembalikan scroll ke atas.
- Login, Profile, Detail dan Progression memakai dua kolom wrap-content dalam satu scroll utama. Di lebar <600dp atau fontScale >1.3, panel menjadi vertikal.
- Sanctum memakai satu scroll utama: ritual memiliki tinggi terbatas, kontrol kanan tidak lagi memiliki scroll bersarang. Keep/Discard tetap di panel ritual; halaman bisa digeser untuk mencapai kontrol bawah.
- Collection, Codex, Daily dan Achievements: kolom grid memperhitungkan ukuran font. Padding kartu diperkecil.
- Prompt, History, Shop, Settings dan Review tetap memakai scroll utama dengan padding bawah. Prompt tetap tersedia sampai tahap migrasi yang direncanakan.
- Tombol umum menggunakan teks English 11sp dengan minimum tinggi 48dp; warna teks ditetapkan konsisten.

## Audit dan batas verifikasi
Pemeriksaan dilakukan pada struktur kode semua route: Lobby, Sanctum, Collection, Review, Progression, Prompt, Codex, Daily, Shop, Achievements, Profile, History, Settings, Detail, More dan Login.
Java compiler parser berhasil membaca 12 file Java sebelum pengemasan. Perbandingan baseline memastikan backend dan engine tidak berubah. Ini belum merupakan kompilasi Android/lint atau pengujian layar/emulator. Kesesuaian visual pada ponsel perlu diperiksa setelah workflow berhasil.

## Pemasangan
1. Ekstrak ZIP, upload isi genesis-android-main ke root repo yang sama, dan timpa file terkait.
2. Jalankan workflow Build Genesis Android pada commit terbaru.
3. Setelah build dan database-tests berhasil, pasang APK sebagai update.
Tidak perlu SQL baru atau mengganti Variables Supabase.

## Pemeriksaan di ponsel
- Lobby: Daily, Achievements, Shop dan Codex terlihat; Sanctum lebih besar dan bisa ditekan.
- Reduce motion ON: pulse logo/tombol berhenti; indikator loading tetap menunjukkan proses.
- Coba login, rename, favorite dan upgrade: logo dan teks loading berada di tengah, keyboard tidak menutupi.
- Buka semua halaman dan Back; periksa scroll sampai tombol terakhir.
- Detail dan Progression: coba geser dari kedua kolom sampai bawah.
- Prompt: pastikan End of prompt dapat dijangkau.
- Sanctum: periksa Keep/Discard, kontrol kanan terakhir, serta hasil 1x/10x tetap dalam Sanctum.
- Coba font sistem lebih besar serta keluar/masuk aplikasi untuk memeriksa layout dan lifecycle.
