# Genesis V18.7 — Visual Consistency

Patch berdasarkan V18.6. Menyertakan source MainActivity terbaru dan workflow SDK yang sudah diperbaiki.

## Perubahan
- Bingkai panel/tombol lebih tipis dengan permukaan gelap, aksen emas dan highlight teal yang lebih ringan.
- Teks isi memakai bobot normal. Judul dan tombol tetap tebal; judul halaman memiliki garis aksen pendek.
- Transisi perpindahan halaman 160 ms: sedikit perubahan opacity dan pergeseran 5dp. Tidak diputar ulang untuk refresh/filter/Load more yang hanya memanggil render.
- Animasi halaman dibatalkan serta posisi dipulihkan saat render atau aplikasi pause.
- Reduce motion langsung menonaktifkan transisi dan state animator tombol yang sedang terpasang.
- Ukuran sentuh tombol, ikon dan badge lokal, loading, filter Collection dan pemulihan koneksi dipertahankan.

Tidak menambah ilustrasi, musik, animasi karakter atau sistem battle. Prompt/Artwork masih tersedia sampai tahap migrasi berikutnya. Tidak ada perubahan backend/ekonomi.

## Pasang
Ekstrak patch lalu upload folder app dan .github ke root repo yang sama. Timpa file bernama sama, jangan menghapus file lain. Jalankan Build Genesis Android pada commit baru dan pasang APK setelah berhasil. Tidak perlu SQL atau perubahan Variables Supabase.

## Validasi
Parser compiler Java berhasil membaca 12 file Java. Ini hanya pemeriksaan sintaks, bukan kompilasi Android/lint. Tampilan/emulator dan lifecycle pada ponsel belum diuji.

## Periksa pada ponsel
- Lihat label tombol aktif/nonaktif serta panel Collection, Profile, Detail, Sanctum dan Settings.
- Berpindah Lobby ke halaman lain lalu Back: transisi singkat, konten kembali utuh.
- Ketuk Load more: tidak ada transisi halaman berulang.
- Aktifkan Reduce motion: perpindahan langsung tanpa efek geser, tombol tidak mengecil saat ditekan.
- Minimize aplikasi ketika transisi berlangsung lalu buka lagi: konten tidak redup atau bergeser permanen.
- Periksa teks dengan ukuran font sistem besar dan pastikan seluruh tombol terakhir bisa dijangkau.
