# Genesis V18.5 — Connection Recovery

Patch untuk repository V18.4 yang sudah berjalan. Tidak memerlukan SQL baru.

## Perubahan
- Loading memiliki label spesifik untuk sign in/out, upgrade, training, evolution, favorite, rename, reward dan refresh. Operasi lain memakai label umum.
- Artwork thumbnail memakai emblem cadangan saat menunggu. Jika gagal ada teks terlihat dan gambar bisa diketuk untuk retry.
- Thumbnail tersimpan di cache aplikasi hingga sekitar 32 MiB, dengan penghapusan file lama. Identitas cache mencakup akun, path dan updated_at. File rusak diunduh ulang; kegagalan menulis cache tidak menggagalkan tampilan gambar.
- Sesudah kegagalan task saat sudah login, layar Reload account menggantikan konten lama. Back tidak melewati pemulihan; setelah refresh berhasil kembali ke Lobby.
- Busy guard dipasang sebelum persiapan mutation. Permintaan receipt menyimpan request key sebelum kirim dan menggunakannya kembali untuk aksi/parameter yang sama jika belum selesai. Kunci dihapus setelah respons dan refresh berhasil.
- Tidak melakukan replay otomatis saat aplikasi dibuka ulang. Startup memuat state server. Bila permintaan sebelumnya masih belum pasti, ulang dengan parameter yang sama memakai key tersimpan (untuk RPC yang mendukung receipt); periksa hasil server dahulu.
- Perbaikan setup-android packages disertakan agar paket tools lama tidak diminta.

## Batasan
Cache ini untuk thumbnail artwork, bukan seluruh data game/offline mode atau paket aset unduhan. Emblem dan ikon bawaan tetap berada di APK.
Perlindungan receipt berlaku untuk pemanggilan mutate yang memang mendukung receipt server; tidak menjadi jaminan exactly-once untuk seluruh endpoint. Pemulihan meminta refresh, bukan menganggap tindakan gagal dan langsung mengirim ulang.
Pemeriksaan sintaks 12 file Java berhasil. Kompilasi Android, lint, emulator, jaringan lambat/terputus dan restart saat transaksi BELUM diuji di lingkungan ini. Workflow dan perangkat menjadi pemeriksaan berikutnya.

## Instalasi
1. Ekstrak ZIP, upload folder app dan .github dari patch ke root repo V18.4 yang sama; timpa file terkait termasuk .github/workflows/android.yml.
2. Jalankan Build Genesis Android pada commit terbaru.
3. Setelah build dan database-tests berhasil, pasang APK sebagai update.
Variables Supabase dan database tetap digunakan. Tidak perlu SQL atau uninstall.

## Checklist perangkat
- Login, rename, favorite, training: periksa teks loading sesuai proses.
- Koneksi lambat saat membuka Collection: emblem tetap terlihat sambil menunggu artwork.
- Artwork gagal: teks retry terlihat, ketuk gambar setelah internet kembali.
- Buka kembali artwork yang sama setelah restart: thumbnail dapat berasal dari cache, sementara akun tetap memerlukan koneksi.
- Putus jaringan ketika menyimpan: muncul Reload account; Back tidak membuka layar lama. Sambungkan kembali dan reload, lalu periksa hasilnya sebelum mengulang.
- Ketuk aksi cepat dua kali: pastikan hanya satu proses berjalan.
- Tutup aplikasi saat request receipt aktif, buka lagi dan cek state server sebelum mengulang aksi identik.
- Ganti akun: artwork akun sebelumnya tidak tampil pada akun berbeda.
