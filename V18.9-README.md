# Genesis V18.9 — Optimized Assets

Source Android lengkap berdasarkan V18.8, dengan UI dan workflow sebelumnya.

72 PNG: 61.71 MiB menjadi 26.42 MiB, pengurangan 57.2%. Ini ukuran file aset, bukan ukuran APK terukur.
- Ikon lobby maksimum 256px; emblem maksimum 512px; branding dan badge maksimum 1080px, rasio dipertahankan.
- PNG RGBA dipertahankan. Resize mengurangi detail pada pembesaran; master asli tetap berada dalam arsip V18.4 serta paket ikon/badge sebelumnya, tidak dimasukkan ke APK ini.
- Loader ikon/badge disesuaikan agar tidak memperkecil hasil optimasi dua kali saat decode.
- Manifest dan pemeriksaan source/APK mencakup semua 72 PNG.
- Suara/musik dan logika permainan tidak diubah.

## Pemasangan
Ekstrak ZIP. Upload ISI folder genesis-android-main ke root repository yang sama. Timpa gambar, source, tools/verify-images.py, dan app/src/main/assets/image-manifest.json bersamaan. Sertakan workflow yang sudah diperbaiki. Jalankan Build Genesis Android lalu pasang APK setelah semua pemeriksaan berhasil. Tidak perlu SQL atau perubahan Variables Supabase.
Jangan upload ZIP saja, dan jangan menghapus repository. Master resolusi tinggi jangan disalin kembali ke app/src/main/assets karena akan membesarkan APK.

## Verifikasi dan keterbatasan
Semua PNG dibaca kembali; hash 72 gambar source terverifikasi. Ikon Sanctum hasil optimasi diperiksa secara visual. Build Android/lint, ukuran APK final dan pemeriksaan seluruh UI pada ponsel belum dilakukan. Periksa khusus keterbacaan badge serta emblem di layar besar setelah build.
