# Genesis V18.6 — Collection Tools

Patch untuk repo V18.4 atau V18.5. Menyertakan perubahan Recovery V18.5 dan perbaikan workflow SDK.

## Perubahan
- Pencarian nama, race, class, ID; tombol Search serta aksi Search keyboard.
- Filter rarity/generation, race, class, Favorites/Named/Unnamed dapat digabung.
- Current/Legacy membatasi generasi; pilihan rarity langsung dapat mencakup kedua generasi jika namanya sama.
- Urut Newest, Oldest, CP tinggi, level tinggi, atau nama A–Z. Newest mengikuti urutan created_at dari server.
- Jumlah hasil cocok dan jumlah tampil diperlihatkan; Load more bekerja atas hasil filter dan urutan.
- Reset filters mengembalikan pencarian dan semua pilihan.
- Clean up matching hanya memilih kandidat tanpa nama dan bukan favorit yang cocok dengan filter TERAPLIKASI. Ketik Search lalu terapkan sebelum cleanup.
- Dialog daftar kandidat dan konfirmasi akhir tetap tersedia. Kandidat tercentang awal seperti versi sebelumnya; periksa dan batalkan centang yang ingin dipertahankan.
- Batas 1.000 pilihan per penghapusan sesuai kontrak backend; daftar tidak dipotong diam-diam.
- Perlindungan nama/favorit server pada migrasi V17.2 tetap digunakan, termasuk validasi perubahan state sebelum penghapusan.
- Pilihan Collection direset ketika logout; tidak disimpan permanen melewati restart aplikasi.

## Memasang
Ekstrak patch, upload folder app dan .github ke root repo yang sama. Timpa tiga file terkait, jangan hapus aset atau file lain. Jalankan Build Genesis Android pada commit terbaru dan pasang APK setelah kedua job berhasil. Tidak perlu SQL baru atau perubahan Variables Supabase.

## Validasi
Pemeriksaan sintaks 12 file Java menggunakan compiler parser berhasil. Backend dan engine tidak berubah dibanding basis V18.5. Build Android/lint dan pengujian UI/runtime belum dilakukan di sini.

## Periksa di ponsel
1. Cari sebagian nama dan ID dengan tombol serta keyboard Search.
2. Gabungkan race + class + rarity; reset lalu pilih Favorites/Named/Unnamed.
3. Urut CP/level/nama, lalu Load more dan periksa urutan tetap konsisten.
4. Periksa hasil kosong dan reset.
5. Buka cleanup pada filter sempit; pastikan daftar kandidat cocok, tidak ada favorit/nama. Cancel tidak mengubah koleksi.
6. Uji konfirmasi menggunakan karakter yang memang ingin dibuang; periksa hasil setelah refresh.
7. Jika kandidat di perangkat lain berubah menjadi favorit/bernama, server harus menolak daftar yang sudah usang.
