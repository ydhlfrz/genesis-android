- Badge mempertahankan proporsi gambar dan memiliki fallback gambar vektor.

Database, account, economy, hasil karakter, dan progression tidak diubah. Prompt/Artwork masih tersedia pada tahap 1; penghapusan masuk tahap transisi.

## Memasang
1. Ekstrak ZIP.
2. Upload ISI folder genesis-android-main ke root repo Android yang sama dan timpa file yang sesuai. Jangan menghapus repository.
3. Pertahankan Variables Supabase yang sudah berfungsi.
4. Commit perubahan lalu jalankan workflow Build Genesis Android yang sudah tersedia.
5. Setelah workflow berhasil, unduh APK baru dan pasang sebagai update. Jangan uninstall atau menghapus data aplikasi.

Tidak perlu menjalankan SQL baru untuk tahap ini.
